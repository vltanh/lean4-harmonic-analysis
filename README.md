# VectorValuedHarmonicAnalysis

A Lean 4 library of harmonic analysis for functions with values in Banach spaces: the Hilbert transform
and the Littlewood–Paley inequality for UMD spaces, matrix-valued Hardy spaces on the circle, and the
noncommutative Paley and Khintchine inequalities.

**Status.** In progress: the statements are in place; proofs are being written (`scripts/Audit.lean` lists
the declarations that still depend on `sorry`).
